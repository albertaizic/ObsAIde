# ObsAIde v0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement five major feature areas for ObsAIde v0.3.0: Vault Search, Interactive Quiz Mode, Wikilink Suggestions, Conversation Branching, and Assistant Profiles — all working together as a cohesive enhancement to the existing Obsidian AI assistant.

**Architecture:** Build on the existing modular structure (providers/, chat/, context/, actions/, prompts/, settings/, ui/, utils/). Each feature adds new modules while reusing existing infrastructure for context resolution, provider communication, settings persistence, and UI patterns. No vector databases, no background indexing, no external search infrastructure — all features are local-first and Markdown-only.

**Tech Stack:** TypeScript, Obsidian API, esbuild bundler, vitest tests. No new heavy dependencies.

**Spec:** User requirements in the conversation context (ObsAIde v0.3.0 specification with five feature areas)

## Global Constraints

- Version must be updated to `0.3.0` in `manifest.json`, `package.json`, `versions.json`
- Only `.md` vault files are AI knowledge/context — no PDF/image/file support
- No background scanning, indexing, or telemetry
- No vector databases or embedding/RAG infrastructure
- AI output never written to a note without explicit user action
- Privacy maintained: vault search and wikilink discovery are local; only explicitly selected Markdown context sent to providers
- Performance: lazy initialization for vault search/index state; debounce/throttle expensive operations
- Tests: all existing 324 tests must pass; new tests added for each feature area
- Build must pass: `npm run build`, `npm run lint`, `npm test`
- Commits: ~5-8 logical commits with clean subject lines
- No pushing to remote
